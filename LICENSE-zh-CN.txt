3. 修改声明

   本项目是基于上述官方项目的修改版本，Android 手机端适配内容：

   - Android 原生运行时集成：将 Termux 构建的 Node.js 24.22.3 嵌入 APK
     （jniLibs + ProcessBuilder 启动，无 NDK），并修补 Android 平台的
     CA bundle、flock、SELinux 硬链接、时区等运行时差异
   - Android 应用壳：前台服务 + 沉浸式 WebView 承载官方 Web UI，
     token 自动认证与运行时载荷解压
   - 移动端 profile 裁剪：基于 DSH 自身的 patch 机制禁用桌面专属组件，
     新增 --profile android
   - 凭证模型：分发版零内置凭证，用户在应用内 Sign in / Add API Key，
     凭据仅保存在设备应用私有目录

   DSH 运行时本体（@deepseek-ai/* node_modules）不在本仓库中；构建 APK
   时按上游项目打包，遵循其原始 MIT 许可证与版权声明。
